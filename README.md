# Quiz App 🎯

A simple quiz application built with **HTML, CSS, and JavaScript**.

## Features

* Multiple-choice questions
* Correct/incorrect answer feedback
* Score tracking
* Restart quiz functionality
* JavaScript ES Modules

## Technologies

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
quiz-app/
├── index.html
├── style.css
├── script.js
└── questions.js
```

## How to Run

Open the project with **VS Code + Live Server** and start the quiz.

## Preview

A simple and interactive quiz for practicing basic web development concepts.
